Politika zasebnosti

Velja od 18. 11. 2026.

Na kratko

  • LYRA teče na napravi uporabnika. Podatki se shranjujejo samo tam – ni skupnega strežnika in ni oglaševanja.
  • Podatki iz Googla se uporabljajo samo za prikaz in funkcije v LYRA, ki jih uporabnik sam vklopi. Ne delimo jih in ne prodajamo.
  • Gmail LYRA samo bere (pošte ne pošilja, ne briše in ne spreminja).
  • Dostop lahko uporabnik kadar koli prekliče.

Kje so podatki

Žetoni za dostop do Googla so šifrirani (AES-256-GCM) v bazi na napravi uporabnika. Podatki iz Googla se hranijo le kratek čas za hitrejši prikaz (predpomnilnik) ali kot povezave za usklajevanje (npr. kateri opravek v LYRA ustreza kateremu v Google Tasks). Vsebina e-pošte se ne shranjuje trajno, razen kratkih povzetkov za prikaz.

Deljenje

Podatkov Googla ne delimo s tretjimi osebami, jih ne prodajamo in jih ne uporabljamo za oglaševanje ali učenje modelov umetne inteligence. Vsebina e-pošte se ne pošilja pomočnikom umetne inteligence ali botom, razen če uporabnik to izrecno vklopi v nastavitvah; tudi takrat samo za odgovor na njegovo zahtevo.

Uporaba in prenos podatkov, prejetih prek Google API, sledita Google API Services User Data Policy, vključno z zahtevami Limited Use.

Preklic in izbris

Povezavo z Googlom uporabnik odstrani v LYRA (Nastavitve → Povezave → Google → Odjava), kar prekliče žeton in izbriše shranjene žetone. Dostop lahko prekliče tudi na myaccount.google.com/permissions. Ker so podatki na napravi uporabnika, jih ta izbriše z izbrisom povezave ali namestitve.

Privacy policy

Effective 18 November 2026.

Summary

  • LYRA runs on the user's own device. Data is stored only there – there is no shared server and no advertising.
  • Google user data is used only to provide features inside LYRA that the user turns on. It is not shared or sold.
  • Gmail access is read-only (LYRA does not send, delete or modify mail).
  • The user can revoke access at any time.

Google data used

Service (scope)Purpose
Google Calendar (calendar.events, calendar.calendarlist.readonly)Show events in LYRA and add events the user creates in LYRA.
Google Tasks (tasks)Synchronise the user's task lists between LYRA and Google Tasks (read and write).
YouTube (youtube.readonly)Show new videos from subscriptions and search videos – read-only.
Gmail (gmail.readonly)Show important mail (sender, subject, first line, time) according to rules set by the user – read-only.
Basic profile (openid, email)Show which account is connected.

Storage

Google access tokens are encrypted (AES-256-GCM) in a database on the user's device. Google data is kept only briefly as a cache for display, or as links needed for synchronisation. Email content is not stored permanently beyond short excerpts for display.

Sharing

Google user data is not shared with third parties, not sold, and not used for advertising or to train AI models. Email content is not sent to AI assistants or bots unless the user explicitly enables it in settings, and then only to answer the user's own request.

LYRA's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking and deletion

The user disconnects Google in LYRA (Settings → Connections → Google → Sign out), which revokes the token and deletes stored tokens, or at myaccount.google.com/permissions. As data lives on the user's device, removing the connection or the installation deletes it.
